# Simulation & Modeling of Dynamic Systems – Portfolio

Welcome! This repository serves as a **central portfolio** for all my assignments and projects from the course:

**Simulation and Modeling of Dynamic Systems**

Here you can explore the work I have done throughout the course, including offline and online parameter estimation methods, controllers, and system simulations.

---

## Assignments

### 1. [Assignment 1 – Offline Least Squares Estimation](https://github.com/VlachakisTheodoros/simulation-modeling-offline-lse-method)
**System:** Linearized simple pendulum with input torque  
**Methods:** Offline Least Squares Estimation (LSE)  
**Description:**  
- Implementation of LSE to estimate unknown parameters \( m, L, c \)  
- Simulation of system response with given inputs  
- Visualization of estimation errors and comparison with true system  

---

### 2. [Assignment 2 – Online Estimators (Gradient & Lyapunov)](https://github.com/VlachakisTheodoros/simulation-modeling-online-estimators)
**Systems:**  
1. Mass-Spring-Damper (MSD) System  
2. Roll Angle System of an Aircraft  

**Methods:**  
- Gradient Descent (online) estimation  
- Lyapunov-based real-time estimation  

**Description:**  
- Implementation of real-time parameter estimators  
- Analysis with different input signals and external disturbances  
- Visualization of estimated parameters and system errors
